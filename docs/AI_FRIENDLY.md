# AI-Friendly Design

PowerQED is designed for AI agents from day one.

## Semantic Tags

Every entity carries semantic tags.

Examples:

- Asset
- Meter
- EnergyInterval
- GenerationEvent
- ConsumptionEvent
- Claim
- EvidencePackage
- Policy
- Certificate

## API

- OpenAPI documented endpoints
- Stable entity identifiers
- Webhooks for event streams

## AI Use Cases

- AI copilot for energy operations
- Anomaly detection across Evidence Graph
- Policy recommendation
- Claim verification assistance
- Audit question answering

## Design Notes

- AI agents can read, analyze and verify evidence.
- Machine-readable by default.
- Any external AI engine can connect via API.
